# Product Hunt launch draft

## Tagline

Watch 2519 algorithms think, one step at a time

## Description

An offline-capable, open-source algorithms textbook. Every algorithm has a replayable visualization, highlighted pseudocode, a correctness sketch, complexity analysis, real-world uses, references, and a worked example. Built for students, self-learners, and anyone who wants to understand how an algorithm actually behaves.

## First comment

I built this because learning algorithms from static pseudocode never showed me what the data was doing. This tool lets you step forward and backward through every algorithm, inspect each element, and read a plain-language explanation of what just happened.

It is MIT licensed, has no accounts or tracking, runs offline, and ships each algorithm as its own small code chunk. The static docs site gives every algorithm its own citable page.

I am actively adding algorithms and improving explanations. Feature requests and contributions are welcome.
